# Registro de Padrões do Time - SA05

## 1. Padrão de Nomes
- Arquivos: Minúsculas separadas por hífen (ex: `style.css`, `validacao.js`).
- Funções JS: Padrão `camelCase` (ex: `validarFormulario()`, `salvarDados()`).
- Classes CSS: Prefixo de componente (ex: `.c-btn`, `.c-input`).

## 2. Padrão Visual Mínimo
- Espaçamento base: Múltiplos de 8px (margin e padding).
- Botões: Altura padrão de 40px com a cor primária `#0284c7`.
- Avisos: Mensagens de erro posicionadas sempre logo abaixo do campo afetado.

## 3. Padrão de Validação e Mensagens
- Campos Obrigatórios: "Preencha este campo obrigatório."
- Formato Inválido: "Formato inválido. Verifique os dados inseridos."
- Mensagem de Sucesso: "Ação concluída com sucesso!"
- Feedback Visual: Borda vermelha para campos com erro e borda verde para campos válidos.
