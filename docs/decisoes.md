# Registro de Padrões do Time - SA05

## 1. Padrão de Nomes (Arquivos, Funções e Classes)
- **Arquivos:** Nomes em minúsculo separados por hífen (ex: `style.css`, `validacao.js`).
- **Funções JS:** Padrão `camelCase` (ex: `validarFormulario()`, `exibirSucesso()`).
- **Classes CSS:** Prefixo de componente para organização (ex: `.c-btn`, `.c-input`).

## 2. Padrão Visual Mínimo
- **Espaçamento:** Grade base em múltiplos de 8px para `margin` e `padding`.
- **Botões:** Altura padrão de 40px com a cor primária `#0284c7`.
- **Avisos:** Mensagens de aviso e erro posicionadas sempre logo abaixo do campo afetado.

## 3. Padrão de Validação e Mensagens
- **Campos Obrigatórios:** "Preencha este campo obrigatório."
- **Formato Inválido:** "Formato inválido. Verifique os dados inseridos."
- **Mensagem de Sucesso:** "Ação concluída com sucesso!"
- **Feedback Visual:** Borda vermelha em campos com erro e verde em campos válidos.
