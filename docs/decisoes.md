# Registro de Padrões do Time - SA05

## 1. Padrão de Nomes
- Arquivos: Minúsculas separadas por hífen (`style.css`).
- Funções JS: `camelCase` (`validarFormulario()`).
- Classes CSS: Prefixo de componente (`.c-btn`).

## 2. Padrão Visual Mínimo
- Espaçamento: Base de 8px (margin/padding).
- Botões: Altura de 40px com cor `#0284c7`.
- Avisos: Mensagens de erro abaixo do campo.

## 3. Padrão de Validação
- Obrigatório: "Preencha este campo obrigatório."
- Formato Inválido: "Formato inválido. Verifique os dados."
- Sucesso: "Ação concluída com sucesso!"
