# Registro de Melhorias de Código e Boas Práticas (SA03)

## 1. Persistência de Dados via LocalStorage
- **Descrição:** Implementada a salvaguarda local dos dados no navegador.
- **Benefício:** Permite manter os chamados registrados mesmo após atualizar ou fechar o navegador.

## 2. Filtro Combinado Dinâmico e Feedback
- **Descrição:** Aprimorado a busca dinâmica por títulos e setores com feedback visual caso não haja registros encontrados.
- **Benefício:** Melhora a usabilidade (UX) e legibilidade da tabela.

## 3. Validação Acessível e Responsiva
- **Descrição:** Adicionados atributos ARIA, labels associados e mensagens de erro focadas.
- **Benefício:** Garante acessibilidade (WCAG) e facilita o uso via navegação por teclado em qualquer dispositivo.
